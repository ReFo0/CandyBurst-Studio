# 🍬 CandyBurst Studio

**CandyBurst Studio**, Sweet Bonanza tarzında hazırlanmış, tamamen front-end (HTML, CSS, JavaScript) tabanlı bir **slot oyun arayüzü** projesidir.  
Bu proje sadece görsel/demo amaçlıdır, herhangi bir gerçek para veya bahis işlevi içermez.

---

## 🎮 Özellikler

- 🎨 Modern **Glassmorphism** tasarım
- 🍭 6x5 **şeker temalı grid sistemi**
- 💎 Dinamik SVG şeker ikonları
- 🌀 Gerçekçi spin animasyonları
- 💰 Denge (Balance), Bahis (Bet) ve Kazanç (Win) göstergeleri
- 📜 **Paytable (Ödeme Tablosu)** penceresi
- 🌈 Mobil uyumlu (Responsive) tasarım
- ✨ Arka planda animasyonlu partiküller

---

## 🧱 Teknolojiler

- HTML5  
- CSS3 (Flexbox + Grid + Glassmorphism)  
- JavaScript (Vanilla)
